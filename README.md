# Device Preview

웹 페이지 하나를 갤럭시 폴드·갤럭시·아이폰·아이패드 등 여러 기기 화면 크기로 **한 창에 나란히** 띄워 보는 맥 앱입니다.
반응형 UI(특히 모바일 표·목록)가 기기마다 제대로 보이는지 한눈에 확인하는 용도입니다.

## 설치

```bash
brew install --cask stephan1226/tap/device-preview
```

업데이트는 `brew upgrade --cask device-preview` 로 합니다.

## 쓰는 법

1. 개발 서버를 켭니다. (예: `npm run dev` → `http://localhost:5173`)
2. Device Preview 를 열고 위쪽 주소창에 주소를 넣고 Enter 를 누르면 모든 기기가 그 주소로 이동합니다.
3. 오른쪽 「기기」 메뉴에서 볼 기기를 고릅니다.

### 확대 2가지

| 확대 | 바뀌는 것 | 조작 |
| --- | --- | --- |
| **보기 배율** | 기기 화면을 크게/작게 **보기만** 합니다. 페이지 레이아웃(CSS 폭)은 그대로입니다. | 트랙패드 핀치(펴기 확대·모으기 축소), 툴바 슬라이더, ⌘- / ⌘= |
| **브라우저 확대** | 기기 안 브라우저의 페이지 확대(Chrome·Safari 의 확대와 같음)입니다. 화면 크기는 그대로이고 CSS 폭이 좁아집니다. 예: 폴드 접힘 344px 에서 125% → 275px | 툴바 「브라우저」 메뉴, ⌥⌘- / ⌥⌘= / ⌥⌘0 |

브라우저 확대는 기기 카드의 <kbd>Aa</kbd> 버튼으로 기기마다 따로 정할 수도 있습니다. 확대 중인 기기는 카드에 `125% → 275px` 처럼 실제 CSS 폭이 표시되고, 브레이크포인트 배지도 그 폭 기준으로 바뀝니다.

터미널에서 주소를 바로 넘겨서 열 수도 있습니다.

```bash
open -a "Device Preview" --args http://localhost:3000
```

### 조작 모드 2가지

| 모드 | 동작 |
| --- | --- |
| **개별 조작** | 기기마다 따로 클릭·스크롤합니다. |
| **미러 조작** | 아무 기기에서나 한 조작(클릭, 입력, 체크, 스크롤, Enter/Esc/방향키, 페이지 이동)이 **나머지 모든 기기에 똑같이** 반영됩니다. 지금 조작 중인 기기는 테두리와 「조작 중」 표시로 구분됩니다. |

미러 조작은 좌표가 아니라 **요소**를 기준으로 따라 합니다. 레이아웃이 달라 같은 위치에 없어도 CSS 경로 → 버튼 글자·`name`·`placeholder`·`aria-label`·`href` 순으로 같은 요소를 찾아 누릅니다.
모바일과 PC 에서 아예 다른 컴포넌트를 그리는 경우처럼 끝내 못 찾으면 그 기기에 「⚠ 요소 못 찾음」이 잠깐 뜹니다.
스크롤은 픽셀이 아니라 비율로 맞추고, 가로 스크롤되는 표도 같은 비율로 따라갑니다.

### 그 밖의 기능

- **로그인 공유**: 모든 기기가 쿠키·localStorage 를 공유하므로 한 기기에서 로그인하면 나머지도 로그인됩니다.
- **실제 기기 UA**: 기기마다 실제 갤럭시/아이폰/아이패드 User-Agent 를 쓰고, 폰·태블릿은 `navigator.maxTouchPoints` 도 터치 기기처럼 보입니다.
- **정확한 뷰포트**: 배율을 줄여도 페이지가 보는 `window.innerWidth` 는 기기 폭 그대로입니다. 어긋나면 카드에 「실제 N」으로 표시됩니다.
- **브레이크포인트 배지**: 설정(⌘,)에 프로젝트의 미디어쿼리 값(예: `519, 800, 1400`)을 넣으면 기기마다 어느 구간에 걸리는지 배지로 보여줍니다.
- **요소 검사**: 기기 화면에서 우클릭 → 「요소 검사」로 Web Inspector 를 열 수 있습니다.
- 기기별/전체 가로·세로 회전, 전체 뒤로·앞으로·새로고침

### 단축키

| 키 | 동작 |
| --- | --- |
| ⌘L | 주소창 |
| ⌘R | 전체 새로고침 |
| ⌘[ / ⌘] | 전체 뒤로 / 앞으로 |
| ⇧⌘M | 개별 ↔ 미러 조작 전환 |
| ⇧⌘O | 전체 회전 |
| ⌘- / ⌘= | 보기 축소 / 확대 |
| ⌥⌘- / ⌥⌘= / ⌥⌘0 | 브라우저 축소 / 확대 / 100% |

## 한계

- 렌더링 엔진은 모두 맥의 WebKit(Safari)입니다. 안드로이드 Chrome 고유의 렌더링 차이까지는 재현하지 않습니다.
- 마우스 입력이라 `(pointer: coarse)`, `(hover: none)` 미디어쿼리와 터치 이벤트는 흉내 내지 않습니다.
- 높이는 ±1px 오차가 있을 수 있습니다. (폭은 정확합니다)
